## Public Kaggriculture agents

`rust/kagg_env/src/v27_script.rs` is a per-step action table generated by
`scripts/extract_v27_script.py` from the public "v27" Kaggriculture agent by
Kaggle user [kaitofukami](https://www.kaggle.com/kaitofukami). The weed repair
and sell-ordering logic of that agent is ported to Rust in
`rust/kagg_env/src/core.rs`. Public Kaggle notebooks are released under the
Apache License 2.0; its text is in
[`licenses/Apache-2.0.txt`](licenses/Apache-2.0.txt).

The other public agents used as opponents and evaluation references are named
in `src/kaggriculture/opponents.py`. Their source is not included in this
repository.
